# Toldaléktorony

A magyar nyelv gépezete, 2. darab: a toldalékok sorrendje toronyként – tő, szám, gazda, rag.

Játszható a böngészőben: https://buhallamate-del.github.io/Toldalektorony/

## Multiverzum és heti toronyfutam

- A Toldaléktorony a szerző többi játékával közös naplót vezet; az oldal alján a „Más világok” kártya mutatja, hol jártál már.
- **Heti toronyfutam:** 90 másodperc, mindenkinek ugyanazok a (géppel generált) szavak a héten; minden hibátlan torony egy pont. A heti rangsor egy nyilvános MQTT üzenetközvetítőn (HiveMQ) megy át; a múlt heti győztes tornya aranyszegélyt kap. A könyvtár: `vendor/mqtt/` (MIT licenc).
